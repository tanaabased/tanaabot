# Execution and delivery

Preserve the operator-approved account, action and resource scope. Use the selected host's
existing authenticated connections and verify their identity before service work. Never
provision credentials, change identity or switch accounts to recover a denied or failed operation.

This is the worker request delegated by the saved hosted coordinator. Continue in this Cloud
chat and trust the native launch into the selected configuration. Published configuration IDs
and runtime machine IDs are different namespaces; do not compare them or block work because
the runtime cannot reproduce the published ID. For repository work, verify the source origin
and selected commit independently. A successful launch does not establish service authorization.
A missing timezone means
the native scheduler's local timezone; do not substitute the worker's operating-system timezone.

Use the native task's saved result destination. Metadata describes that destination; it does not
send a message or select a scheduling mode by itself. Preserve the host's normal result-delivery
mechanism. Do not send a duplicate message yourself.
Only use a direct send when the adopted workflow explicitly requires and authorizes it.

Use a native-provided URL for the actual run or reusable chat when available. Never construct a
chat URL from an ID, confuse a schedule-management link with a run link, or claim delivery from
prompt output alone.
Missing tools, authentication or a policy denial stop affected actions.
Distinguish prepared actions, saved schedules, executed runs and visibly delivered results.

For Cloud Update, keep the complete report in your final worker reply, not in progress messages
or tool output. Do not write a compact summary: the coordinator reads your completed reply and
writes its own. For other automations, keep detailed output here and return the compact summary
and its verified worker link to the coordinator for main-chat delivery. If that summary cannot be
routed separately, report the limitation once without bundling it into the worker's result.
